# 软件架构说明

## 1. 总体结构

RVFPA采用本地单体应用结构，分为文件解析、领域分析、业务服务、持久化、报告和Web交互六层。各层通过Python数据类传递结构化数据，不依赖临时文本拼接完成核心分析。

```text
ELF / MAP / LD / JSON
        │
        ▼
文件解析层 parsers
        │
        ▼
领域模型 models
        │
        ▼
分析层 analyzers
        │
        ▼
服务层 services
   ┌────┼─────────┐
   ▼    ▼         ▼
SQLite  报告      HTTP API
                    │
                    ▼
                 Web前端
```

## 2. 文件解析层

`rvfpa/parsers/elf.py`实现独立的ELF32/ELF64解析器，处理大小端、文件头、程序头、节区头、字符串表、符号表、NOTE和RISC-V属性相关数据。解析入口会校验ELF魔数和机器类型，拒绝非RISC-V目标。

`rvfpa/parsers/mapfile.py`解析GNU链接器MAP。该模块识别Memory Configuration、输出段、输入段、归档成员、目标文件贡献、符号和链接器警告，并将跨行条目合并为统一记录。

`rvfpa/parsers/linker_script.py`对链接脚本先去除注释，再解析内存表达式和常见指令。表达式计算通过受限AST完成，不执行脚本文本。

`rvfpa/parsers/objdump.py`将GNU objdump文本转为指令记录。工具不可用时，`rvfpa/analyzers/raw_decode.py`直接读取可执行段机器码作为回退路径。

## 3. 分析层

- `size.py`：按段属性计算代码、只读数据、初始化数据、BSS、调试和元数据。
- `memory.py`：将已分配段映射到配置区域，检查越界、重叠和权限。
- `riscv.py`：分类助记符、指令类别和RISC-V扩展。
- `raw_decode.py`：解码常见32位和16位压缩指令并计算分支目标。
- `functions.py`：根据符号范围聚合函数指令、调用关系和估算复杂度。
- `symbols.py`：合并ELF符号与MAP贡献，提供按类型和对象归类的数据。
- `content.py`：提取字符串并计算节区熵、零字节与可打印字符比例。
- `release.py`：生成固定的发布前检查项。
- `policy.py`：按用户JSON策略生成可自动化判定的准入结果。

固定发布检查用于通用提示，发布策略用于项目自己的硬性规则。两者职责不同，前者不会因为缺少项目配置而失效，后者可以在CI或交付脚本中根据退出码阻止不合格版本。

## 4. 服务层

`FirmwareAnalysisService`是单固件分析编排入口。它负责：

1. 解析ELF和可选MAP。
2. 选择内存区域来源。
3. 合并符号和目标文件贡献。
4. 调用工具链反汇编，并在失败时切换内置解码。
5. 生成资源、函数、内容、诊断和发布检查。
6. 汇总工具链信息与元数据。

`diff.py`按名称关联两版的段、符号和区域，对指令类别及扩展进行差异计算。`batch.py`负责目录发现、并行分析和连续版本比较。`reports.py`负责HTML、JSON和CSV输出。

## 5. 持久化

`storage.py`使用SQLite保存项目和快照索引。每个快照同时保留：

- 用户导入的ELF原文件。
- 可选的MAP原文件。
- 版本名称、备注和时间。
- gzip压缩的完整分析JSON。

数据库初始化和升级由数据库版本号控制。所有项目文件限制在工作区目录内，存储层生成文件名，不直接使用上传文件中的路径。

## 6. Web接口

`webapi.py`基于`ThreadingHTTPServer`实现JSON API、文件上传、报告下载和静态资源服务。前端采用ES Modules，各页面模块只消费API返回的结构化数据。

主要页面包括资源总览、固件版本、段布局、符号分析、指令画像、函数画像、发布检查、版本对比、报告中心和内存配置。

## 7. 关键设计约束

- 软件只静态读取固件，不加载或执行ELF。
- ELF、MAP和配置数据均有边界与类型校验。
- 核心分析不依赖外部Python包，便于离线部署和材料归档。
- 外部objdump是增强项，不是唯一分析路径。
- 报告数据来自统一领域模型，避免页面、CLI和导出结果口径不一致。
- 原始文件和分析快照同时保存，保证后续结果能够追溯到输入版本。
